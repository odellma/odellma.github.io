# Current projects

## Fisheries Genome Visualization Tool

I am developing a cloud-based genome visualization and bioinformatics platform that integrates publicly available genomic resources, including NCBI, Ensembl, Gene Ontology Consortium, KEGG, and UniProt. The project aims to transform genomic sequence data, gene annotations, and functional information into interactive visualizations that reveal patterns in genome organization.

By grouping genes according to physiological systems, molecular functions, and biochemical pathways, I hope to better understand how genome structure relates to biological function. My long-term goal is to create tools that support conservation genomics by helping researchers explore genome architecture and identify genetic markers relevant to adaptation, population structure, and biodiversity conservation.


### Technology and Sources
Technologies: SvelteKit, TypeScript, Tailwind CSS, D3.js, Ideogram.js, C#/.NET, SQL Server, Azure Static Web Apps, Azure SQL, Azure Blob Storage, Python, Pandas, Biopython, GitHub Actions.

Data Sources: NCBI, Ensembl, Gene Ontology Consortium, KEGG, and UniProt.
